Understand the context of how we moved from textual models and to enhance the system capablities we improve them to support mulitple context types which we called Multimodal AI. Then we enhance these systems to make sure that they will have the ability to access real time information for which tool interface is created where we allow model to communicate with tools and data sources in real time (also called Model Context Protocol). This is the point which focus the topic where i understand how they communicate in spcific json format which is standardized and have stable payload arguments to ensure reliablity and avoid cofusion during multiple tool calls in one turn. Also shows the  4 step loop every MCP follows (Discribe > Decide > Execute > Observe).
